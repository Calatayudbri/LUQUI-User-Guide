Descripción

El Motor Gráfico LUQUI Engine es un framework moderno y flexible diseñado para el desarrollo de videojuegos. Implementa una arquitectura basada en componentes (ECS - Entity Component System) que permite crear aplicaciones interactivas de alto rendimiento.

Desarrollado como parte del proyecto académico de la asignatura Programación de Motor Gráfico, este motor gráfico proporciona las herramientas necesarias para la creación de gráficos 3D, gestión de entrada, y más funcionalidades esenciales para el desarrollo de juegos.

El motor está construido sobre OpenGL para el renderizado gráfico, GLFW para la gestión de ventanas e input, y varias bibliotecas auxiliares que facilitan tareas comunes en el desarrollo de videojuegos.

Guía de Instalación

Dependencias Necesarias

Para poder compilar y ejecutar el motor, necesitarás tener instaladas las siguientes herramientas:

  • Visual Studio 2022 - Entorno de desarrollo integrado
  • Conan - Gestor de paquetes para C/C++
  • Python 3.12 - Necesario para algunas herramientas de compilación
  • CMake - Sistema de generación de archivos de compilación

Proceso de Compilación

  1. Descarga el código fuente del motor desde el repositorio (archivo ZIP)
  2. Abre la consola "Developer Command Prompt" de Visual Studio
  3. Navega hasta la ruta del repositorio descargado
  4. Ejecuta los siguientes comandos en secuencia: 
    ./tools/gendeps.bat
./tools/premake/premake5.exe vs2022
./build/LUQUI.sln
  5. La solución se abrirá en Visual Studio 2022 donde podrás compilar y ejecutar el motor

Verificación de la Instalación

Para verificar que la instalación se ha realizado correctamente, puedes ejecutar la aplicación de demostración incluida en la solución. Si la ventana se abre correctamente y muestra un cubo renderizado, la instalación ha sido exitosa.

Características Principales

Sistema de Entidades y Componentes (ECS)

Arquitectura flexible para la gestión de objetos del juego, permitiendo la composición de entidades con diferentes componentes.

Renderizado 3D

Soporte para modelos 3D, texturas y sistemas de iluminación basados en OpenGL.

Sistema de Input

Gestión completa de entrada de teclado y ratón a través de GLFW.

Sistema de Jobs

Programación de tareas multihilo para mejorar el rendimiento en sistemas multicore.

Sistema de Shaders

Programas de shader personalizables para efectos de renderizado avanzados.

Gestión de Ventanas

Creación y gestión sencilla de ventanas de aplicación con GLFW.

Scripting con Lua

Integración de scripts Lua para la lógica de juego personalizada.

Sistema de Cámara

Controles de cámara completos al estilo de los mejores motores de la industria.

Carga de Modelos

Soporte para varios formatos de modelos 3D a través de Assimp.

  // Inicializar la ventana (Inicio del programa)
  auto WS = WindowSystem::make();
  auto window = Window::make(LUQUI_Window_Width, LUQUI_Window_Height, "LUQUI");
  if (nullptr == window->window) {
    return -1;
  }
  window->setCurrentWindowActive();

// Creación del sistema de ventanas de debug
  LuquiImgui LuquiImgui(&window.value());

// Ciclo de juego
    LuquiImgui.NewFrame();

    glClearColor(0.4, 0.4, 0.4, 1.0);
    glFrontFace(GL_CCW);
    glClear(GL_COLOR_BUFFER_BIT | GL_DEPTH_BUFFER_BIT | GL_STENCIL_BUFFER_BIT);
    glEnable(GL_DEPTH_TEST);
    glDepthFunc(GL_LEQUAL);
    glDepthMask(true);
    glEnable(GL_CULL_FACE);
    glCullFace(GL_BACK);
    glEnable(GL_BLEND);
    glBlendFunc(GL_ONE, GL_ZERO);

    LuquiImgui.EntityWindows(ecsmanager);

    
// Colocar al final del código de renderizado
    LuquiImgui.Render();
    window->render();


// Final del programa
  window->~Window();
  WS->~WindowSystem();         
    }

// Inicialización de la lista de componentes tipo Modelo
  ecsmanager.addComponentType();

  auto cube_mesh = std::make_shared("../data/Models/cube/cube.obj", "cube");
  ecsmanager.resources.push_back(cube_mesh);

// Creación de la entidad
  Entity entity1 = ecsmanager.createEntity();

  ecsmanager.editComponent(entity1, [&](RenderComponent& modelComp)   {

  // Dibujar el modelo
  if (transformOpt && modelOpt) {
    renderSystem.drawModel(transformOpt.value(), modelOpt.value(), program);
  }
