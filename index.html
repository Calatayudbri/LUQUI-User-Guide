Bienvenido a LUQUI Engine

LUQUI Engine es un motor gráfico basado en openGL desarrollado por Lucas Calatayud y Enrique López

DEPENDENCIAS

  1. Visual Studio 2022.
  2. Conan
  3. Python 3.12
  4. CMake.

Guía de Instalación

Para instalar LUQUI Engine, sigue los siguientes pasos:

  1. Descarga el archivo zip del motor.
  2. Abrir consola developer command prompt de Visual Studio.
  3. Navegar hasta la ruta del repositorio.
  4. En la carpeta raíz utilizar los siguientes comandos:
    4.1. ./tools/gendeps.bat

    4.2. ./tools/premake/premake5.exe vs2022

    4.3. ./build/LUQUI.sln
